Why your Sage Intacct reports disagree

When Sage Intacct reports tell different stories, the cause is usually dimension sprawl: missing departments, duplicate locations and untagged lines. Five steps fix it for good.

The P&L shows one figure, the location report shows another, and the board pack shows a third. In Sage Intacct, this is rarely a calculation problem. It's usually dimension sprawl.

Dimension sprawl means missing departments, duplicate locations and transaction lines that were never tagged. Each report slices the same transactions differently, so each tells a slightly different story.

The underlying numbers are usually fine. What's missing is consistent tagging. Five steps fix it, so every report tells the same story.

Step 1: Map your dimensions

Agree what each dimension value means, and retire duplicates nobody uses. If "NYC", "New York" and "NY Office" all exist as locations, keep one and merge the rest.

Step 2: Make them required

Set bills, invoices and journals so they can't post without a department and a location. Requiring dimensions at entry stops new gaps from opening.

Step 3: Clean up the history, once

Existing untagged lines still need fixing. Tag every line for the year and reclass anything posted to the wrong place. It's a one-time job, and Step 2 keeps it from piling up again.

Step 4: Report by dimension

Build the P&L, the location view and the board pack on the same tags. When every report reads from the same dimensions, they can't drift apart.

Step 5: Add a close check

Add one rule to the month-end close: untagged lines must be zero before the month is closed. This keeps the sprawl from coming back.

In short

Tag it once, check it every month, and every report agrees.
